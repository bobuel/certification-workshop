    # Northstar certification charter — draft revision 1

Fictional/synthetic case. Product 1.0; working credential version 1.0. Owner: Morgan Lee (fictional). No approvals or live effects.

Claim: an implementation consultant can prepare and verify a bounded customer deployment using documented procedures, recognize a failure, and escalate safely. Audience: twenty partner consultants expected to implement next quarter. Independent performance means following procedures within a bounded implementation, preserving evidence and seeking authority when needed.

Included: CSV configuration, reconciliation and release verification; narrow service access, negative tests and token disclosure response; separate restore rehearsal, verification, rollback recommendation and customer-authorized cutover. Excluded: platform architecture, production incident command and commercial project management. Implementation terminology familiarity is a proposed prerequisite; training completion is neither competence evidence nor a decided eligibility requirement.

Course completion records participation. This package samples procedural decisions and evidence interpretation. Nine selected-response scenarios plus three written practicals offer a useful first pilot in the existing LMS and evidence sheets. They do not observe actual software execution or establish prediction of independent field performance. Later observation is needed for stronger execution claims.

Use existing LMS for nine questions and existing restricted document storage for practicals. No new services, lab, purchases or credential provider. LMS format is unnamed/unverified; these are authoring files, not a verified import. Folder separation is an audience convention, not implemented access control or encryption.
