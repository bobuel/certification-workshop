# Contributing

Start with the user journey and an observed gap. Keep core workflows portable and use existing assistant tools. Do not add a service or mandatory provider for local drafting, calculation or review.

Run the checks in AGENTS.md. For a behavior change, add a meaningful regression or negative control and execute the affected realistic case. Keep unit, CLI, authored simulation, independent model, provider and human evidence separate. Preserve failed eval runs; do not repair evaluated artifacts or rewrite historical reports to claim success. A model artifact review is not an expert's acceptance of a certification.

Keep all examples synthetic. Attribute borrowed code in NOTICE.md. Change matching package manifests together, verify the isolated installer, and build the allowlisted ZIP. Do not include real programs, scratch work or credentials in the archive.
