## Product promise

A program owner supplies a brief and sources. The plugin develops a charter, proposed job tasks and study instruments, a blueprint, actual assessment drafts and review materials. The owner can continue with reviewer evidence and pilot data, prepare delivery and policy decisions, and revise the same program when sources change. Ten coordinated skills and a local helper keep source versions, content revisions, exact forms and attributed decisions connected. No new hosted service is required.
