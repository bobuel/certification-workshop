# Certification Workshop 1.0.0

Local distribution finalized 2026-10-22. Publication assets are prepared; no remote repository, directory listing, website or GitHub profile change is asserted by this record.

## Release scope and decisions

The v1 product is a portable certification-development workflow: ten skills, local records/helpers, from-scratch development, review and pilot support, launch preparation, operations reconciliation and maintenance. It requires no new hosted service. The finished [Northstar example](../examples/northstar-v1/CERTIFICATION.md) demonstrates the substantive output.

The owner explicitly delegated the outstanding design review to the assistant. That AI review is complete and attributed in [design-review.md](../examples/northstar-v1/design-review.md), with twelve item-level records and nine authored scoring examples. The example's narrowed claim, explicit rubric points, practical-first delivery and feasible staged study plan resolve the five release-review questions. No independent human acceptance or empirical study is invented.

The release support claim is deliberately limited to the observed environment: Windows, Python 3.11 and the tested Codex CLI workflow. Python 3.10+ syntax and portability are intended; macOS/Linux runtime and the configured 3.10/3.13 CI matrix remain unverified. No installed WSL distribution or alternative Python was available locally, and no infrastructure was added. The earlier candidate proposed cross-platform CI as a universal v1 gate; this release instead limits its supported-platform claim to what was actually tested. Hosted matrix results are required before expanding that claim, not before publishing a Windows-verified development tool.

## Boundaries that remain part of the product

Real certification programs need real job/content evidence, participant handling, delivery verification, standard-setting decisions and accountable authority. These are responsibilities supported by the workflow, not missing plugin infrastructure. The fictional example intentionally has no approved forms or awards. Descriptive arithmetic and AI content review do not establish validity, accreditation or fairness.

Claude metadata is included but Claude activation is unverified. Native desktop UI discovery is distinct from the observed CLI workflow. Public GitHub Actions have not run before a remote repository exists. The website and profile text remain prepared publication copy, with prospective links to verify at publication.

Implemented: v1 workflow, finished example, tests and distribution. Observed: the recorded local checks and bounded native behavior. Published/deployed: not claimed. Design-review delegation: completed by AI; independent human/program acceptance is not claimed.
