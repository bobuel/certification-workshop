# Eventer quality comparison

Compared against the locally installed Eventer 0.1.3 package on 2026-10-22: README, skill collection and shared record contract, eval documentation and artifact rubric, archive/restore instructions, security guidance and package layout. This is a targeted package/workflow comparison, not an exhaustive audit of Eventer's code or every prior conversation.

| Quality characteristic | Certification Workshop implementation |
| --- | --- |
| A complete owner journey | Ten specialist skills cover creation through operations and maintenance. README now starts with the owner's job and continuation examples. No existing exam is required. |
| One portable collection | Matching native manifests, local catalogs, relative skill references, a protected collection installer and allowlisted reproducible ZIP. No new services added. |
| Durable evidence and state | Versioned tasks, competencies, sources, items, decisions and forms; content-bound approvals. Added a concrete handoff/restore reference and explicit maintenance review of practical setups, scoring anchors and candidate guidance. |
| Useful local mechanics | Existing coverage/allocation, bounded form search, form checks, descriptive score analysis, panel summaries, impact and audience exports. Model judgment remains responsible for substantive quality. |
| Realistic phased eval | Added Northstar: raw business/product/workshop sources, creation from scratch, then a fresh-session pilot/product-change decision. Preserved inputs, copied skills, hashes, write-once grades and separate artifact reviews. |
| Honest grading | Negative controls reject evidence loss, fake approvals, bank disclosure and changed outputs. A structurally plausible but shallow fixture deliberately demonstrates why artifact review is required. |
| Safe distribution | Added security/reporting and contributor guidance; package allowlist includes them. Program data remains outside the plugin. |

Eventer has broader observed maturity: multiple event cases and native Codex/Claude installation evidence. Certification Workshop now also has a disposable-profile Codex CLI installation/readback and installed-helper initialization check. Its local collection tests and fresh-agent cases do not establish automatic native skill discovery, Claude activation, cross-platform behavior, real provider operation or SME/candidate acceptance. The goal is the same evidence standard, not matching file counts or claiming identical maturity.

Archive/restore uses existing filesystem/archive tools with hash inventory, source resolution and a historical-analysis replay. There is no additional archive service or background process. See the recorded Northstar results for what was actually observed.
