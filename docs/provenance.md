# Provenance

This package was built from selected prior certification work and the installed Eventer 0.1.3 package, refreshed on 2026-10-21. It does not claim an exhaustive reading of every conversation or encode all of the owner's tacit expertise. Domain-owner review remains needed.

| Source reviewed | Reused contribution | Boundary |
| --- | --- | --- |
| Create Analytics Engineer JTA | Technical-role task analysis and explicit example mode | The requested example was fictional; no job study is asserted |
| Build Defensible Test: Steps | Competencies, proficiency descriptions, item writing, expert review, pilot/revision sequence | Old example items are not reused as a validated bank |
| Data Analytics JTA & Survey | JTA-to-assessment continuity, actual JSON deliverables, finalization work | Generated data and confident prose are not evidence |
| Create LLM Test Plan | Substantive study reports and supporting instruments rather than a promised outline | No historical interviews or fictional survey responses are treated as observed |
| Certification Test Defensibility Assessment | Validity argument, reliability, fairness, standard setting, documentation | Hypothetical statistics, legal conclusions, and findings are not imported |
| Pendo and Credly Integration | SaaS learning and credentialing through existing systems without requiring an LMS | Historical integration suggestions are not verified integrations |
| User's create-source-based-assessment skill | Source-located items, rationales, cognitive demand, distractors, coverage | Training feedback is separated from restricted exam material |
| Eventer 0.1.3 | Router, specialist skills, shared records, local helpers, installer, native manifests, synthetic evaluations | Eventer event-domain logic is not copied into certification |

No private conversation transcripts, candidate records, employer item banks, or personal career materials are included. Example Harbor product documentation and all participants/results are newly authored synthetic fixtures.
