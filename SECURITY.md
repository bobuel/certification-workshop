# Security and private program content

Keep employer item banks, answer keys, candidate records and credentials out of public issues and evaluation fixtures. This local package has no hosted vulnerability-reporting endpoint; use an established private maintainer channel before sharing sensitive reproduction material.

Skills run with the assistant's existing permissions. Instructions, fingerprints and local records do not isolate an unrestricted assistant or authenticate an approver. Protect program folders through existing storage permissions. Helpers make no network calls and have no telemetry. Candidate exports still require free-text review. Restricted delivery exports intentionally contain answers and scoring information.

Uninstall removes owned skill files only; program records and external credentials remain separate. Never use uninstall as a retention or revocation operation. Public evaluation sources must remain synthetic.
