# Certification Blueprint

Read the [method](../certification-workshop/references/method.md#assessment-design) and [records](../certification-workshop/references/records.md). Translate included tasks into assessable objectives at the intended performance level. Explain domain grouping and weight rationale from evidence and owner decisions; do not infer weights from documentation page counts.

Choose methods that can support the credential claim. Include practical exercises and rubrics where performance matters. Distinguish cognitive demand, intended challenge, observed item difficulty and task criticality. Bloom tagging can assist authoring; it does not establish difficulty or require all six levels.

Specify length, item-count weights, time proposal, scoring model, permitted resources, required method counts and excluded content. The local allocation helper implements item-count weighting only; document score-based or multidimensional specifications separately and do not mislabel item percentages as score percentages. Run coverage to surface gaps and rounding. Get consequential design decisions recorded; approval does not originate from a calculated total of 100 percent. Pin blueprint revision, retain prior versions, and record the effect on existing items/forms. Deliver the actual blueprint and mapping with rationale.
