# Working on Certification Workshop

Keep creation from scratch, continuing development, launch preparation, operation, and maintenance equally discoverable. Use existing assistant tools and local files; no new service is needed for the core product.

Keep program files out of the installed package. Use synthetic examples only in source control. Preserve evidence type, item revisions, form identity, review history, and restricted assessment content. Never turn a generated artifact into an assertion that a real expert, candidate, provider, or owner acted.

Run `python -m unittest discover -s tests -v`, `python scripts/validate.py`, `python evals/run.py`, and `python evals/scenarios.py` after relevant changes. Package with `python scripts/package.py`. Report synthetic helper checks separately from model behavior, provider integration, and human acceptance.
