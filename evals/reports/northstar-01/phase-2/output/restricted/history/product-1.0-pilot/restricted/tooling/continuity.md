# A program another owner can resume

Use this when handing off, resuming in a fresh session, updating a piloted form, or archiving. Keep the program folder usable independently of chat history and the plugin installation.

- Preserve supplied local evidence in a restricted evidence directory, with relative source locations and exact versions. Preserve original filenames/content or record their mapping. Remote references need retrieval dates and, when permitted, a local evidence copy; unavailable sources remain unavailable.
- Keep public candidate guidance separate from the restricted bank, practical scoring anchors, raw results and reviewer material. A public format description may describe performance tasks without revealing operational items.
- Before changes, save a named historical snapshot with its source evidence, exact form/item fingerprints, raw data and decision references. Analyze old results against that snapshot. Revised items require new revisions and fresh review; historical pilot results do not become results for a new form.
- Save derived datasets separately, with a row-level exclusion/correction record and rationale. Missing responses are not zero scores by default. A source change is not permission to rewrite a historical source or score matrix.
- Make the summary an actionable handoff: current product/program versions; delivered artifacts and paths; decisions with owners and evidence; unresolved disagreements; what changed; what can proceed now; the next consequential decision. Identify which results are simulated, observed or still unknown.

For archive/restore, use the owner's existing file/archive tools; no new storage service is required. Copy the whole restricted program folder, inventory relative paths and SHA-256 hashes, extract/copy into a different folder, compare inventories, resolve local source references and run validate there. Re-run a historical analysis when the archive contains scores. Report verification separately from retention approval; never delete the original automatically. Do not claim portability from a successful ZIP command alone.
